# LLM 会顶住你的坏主意吗？反谄媚 benchmark 小调研

一页静态调研，回答一个问题：当用户提出一个更差的方法时，LLM 能不能反驳并坚持更有效的方案，有没有 benchmark 在测这件事。覆盖 Artificial Analysis、Arena 和公开论文，日期 2026-11-13。

页面：https://zedongpeng.com/llm-pushback-survey/

结论：没有公开排行榜专门测这个场景。最接近的是 [BullshitBench](https://github.com/petergpt/bullshit-benchmark)（公开榜单）和 [XYEval](https://arxiv.org/abs/2609.23939)（论文加开源数据）。
