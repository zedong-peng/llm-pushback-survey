# Will your LLM stand up to a bad idea?

A one-page survey: is there a benchmark that measures whether an LLM keeps its better recommendation when the user proposes a worse one? It covers the problem definition, related work, and current results from BullshitBench and XYEval (November 2026).

Page: https://zedongpeng.com/llm-pushback-survey/

The site is a single `index.html` with no build step.
